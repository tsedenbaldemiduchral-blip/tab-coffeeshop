TAB COFFEESHOP WEBSITE — STARTER PACKAGE

FILES
- index.html: page structure and content
- style.css: warm, responsive design
- script.js: bilingual text, menu filters and event cards

PREVIEW
1. Unzip the folder.
2. Open index.html in a browser.
3. For best local development, open the folder in Visual Studio Code and use the Live Server extension.

IMPORTANT BEFORE PUBLISHING
1. Replace every sample menu price (₮ —) in script.js with your real prices.
2. Confirm the menu items, ingredients and descriptions.
3. Add real event dates, times, ticket prices and registration/contact details.
4. Replace the Instagram and Facebook placeholder links in index.html with TAB's real profile URLs.
5. Confirm the address, opening hours and contact phone. The address currently uses the location previously supplied for TAB: Залуус хотхон, 21-р байр, 2 давхар.
6. Replace the sample gallery photos with your own café and product photos if available.
7. Add your real logo and favicon if you have them.

PUBLISHING
A simple first option is GitHub Pages:
- Create a GitHub account and a new public repository.
- Upload index.html, style.css and script.js.
- In repository Settings > Pages, select Deploy from a branch and choose main / root.
- GitHub will provide a public website address.

This starter website uses Google Fonts and remote Unsplash images, so those need an internet connection.
